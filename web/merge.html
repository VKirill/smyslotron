Проекты Объединить CSV
Перетащи сюда несколько CSV/TXT (Keys.so, Key Collector, Wordstat…)
или кликни для выбора · всё объединяется прямо в браузере, файлы никуда не загружаются
Формат результата: Запрос;Базовая частотность;Точная частотность;Очень точная частотность;Является топонимом;Является вопросом — готов к загрузке в проект. Повторяющиеся фразы склеиваются: частотности берутся максимальные из всех файлов, флаги объединяются. Колонки в каждом файле распознаются по заголовкам автоматически; файл без распознанной колонки запросов помечается красным и пропускается.
