# Смыслотрон (Semantika Web)

Мини-SaaS для экспресс-кластеризации SEO-ядра по эмбеддингам — без SERP, без GPU,
только API-провайдеры. Загружаешь CSV с фразами → пайплайн дедуплицирует смысловые
дубли, считает до 11 вариантов эмбеддингов, строит HAC-деревья и размечает интенты
через DeepSeek → в браузере крутишь порог объединения и сравниваешь варианты
в реальном времени, без пересчёта на сервере.

Проверено на ядре 33 726 фраз: полный прогон всех 11 вариантов + пофразовая
разметка интентов ≈ **$1.6** себестоимости (≈ $0.000047 за фразу).

## Как это работает

```
CSV (keys.so / Key Collector / Wordstat)
  │  маппер колонок: Запрос · Wordstat · "!Wordstat" · "[!Wordstat]" · Топоним · Вопрос
  ▼
Дедуп смысловых дублей          leмма-мешки (pymorphy3) → кандидаты
  │                             + чанки предлогов + косинус эмбеддинга (0.97 / 0.85)
  ▼                             «молитва матери о дочери» ≠ «молитва дочери о матери»
Эмбеддинги (до 11 вариантов)    OpenAI · Gemini (3 taskType) · Voyage · Qwen
  │                             + бесплатные производные: ансамбль, матрёшечные обрезки
  ▼
HAC (scipy linkage)             complete / average / single → 3 дерева на вариант
  │                             сериализуются в компактный .bin
  ▼
Интенты (DeepSeek)              пофразовая разметка: информационный / коммерческое
  │                             исследование / транзакционный / навигационный
  ▼
Браузер (view.html)             срез дендрограммы union-find на клиенте: ползунок порога,
                                Hard/Средний/Soft, A/B-сравнение колонок, консенсус-
                                подсветка, гео-разрез, экспорт CSV текущего среза
```

Ключевая идея: сервер один раз считает **деревья**, а не кластеры. Порог, режим
связи, минимальный размер группы, целевое гео — всё это клиентские операции над
готовым деревом, поэтому пересчёт мгновенный и бесплатный.

## Варианты эмбеддингов

| Ключ | Модель | Особенность |
|---|---|---|
| `openai` | text-embedding-3-large, 3072d | базовый |
| `gemini` | gemini-embedding-2, taskType=CLUSTERING | базовый |
| `gem_sim` | gemini-embedding-2, SEMANTIC_SIMILARITY | «склеивающий» |
| `gem_query` | gemini-embedding-2, RETRIEVAL_QUERY | поисковый |
| `lemma` | OpenAI по лемматизированному тексту | без словоформ |
| `intent` | OpenAI по фразе с интент-префиксом | интентная близость |
| `voyage` | voyage-3-large, 2048d | «склеивающий», перефразировки |
| `qwen` | text-embedding-v4 (DashScope), 2048d | гибрид, самый дешёвый |
| `ensemble` | конкатенация норм. openai+gemini | бесплатно |
| `openai1536` | матрёшечная обрезка openai до 1536d | бесплатно |
| `gemini768` | матрёшечная обрезка gemini до 768d | бесплатно |

Эмбеддинги кэшируются в `emb_*.npy` пофайлово и **инкрементально**: при пополнении
проекта доэмбеддится только хвост новых фраз.

## Структура

```
app.py          FastAPI: auth (scrypt + cookie-сессии), проекты, загрузка с маппером
                колонок, очередь пайплайна (worker_loop), выдача данных проекта
pipeline.py     самодостаточный uv-скрипт (inline deps): дедуп, эмбеддинги,
                HAC-деревья, DeepSeek-интенты, подсчёт стоимости
web/index.html  кабинет: проекты, drag&drop + модалка-маппер, пополнение фраз,
                статусы, раскладка стоимости
web/view.html   просмотрщик: колонки вариантов, ползунки, консенсус, поиск,
                интент-чипы, целевое гео, экспорт среза
web/merge.html  объединение нескольких CSV в один keys.csv прямо в браузере
projects/       (gitignore) данные проектов: keys.csv, data/*.bin, emb_*.npy, costs.json
semantika.db    (gitignore) SQLite (WAL): users, projects, история пополнений
```

## API (префикс `/semantika/api`)

- `POST /auth/register` · `/auth/login` · `/auth/logout` · `GET /auth/me`
- `POST /uploads` — файл → превью + автоопределение разделителя и колонок
- `POST /projects` — создать проект из загрузки с подтверждённым маппингом
- `GET /projects` · `GET /projects/{pid}` — список / карточка со статусом и стоимостью
- `POST /projects/{pid}/run` — поставить пайплайн в очередь (с выбором вариантов)
- `POST /projects/{pid}/label` — DeepSeek-разметка интентов (инкрементальная)
- `POST /projects/{pid}/append` — докинуть фразы: дубли схлопываются, эмбеддинги доезжают
- `POST /projects/{pid}/target_geo` — целевой регион с синонимами («москва, мск, мо»)
- `GET /projects/{pid}/data/{fname}` — деревья `.bin`, `queries.json`, `meta.json`, `result.csv`
- `DELETE /projects/{pid}`

## Запуск

```bash
cp .env.example .env        # вписать ключи
uv run uvicorn app:app --host 127.0.0.1 --port 8090
```

Прод: PM2-процесс `semantika-web` + reverse-proxy (`/semantika/api/` → `127.0.0.1:8090`),
статика `web/` отдаётся веб-сервером как `/semantika/`.

Пайплайн можно гонять и руками:

```bash
uv run pipeline.py <project_dir> --variants openai,gemini,qwen
uv run pipeline.py <project_dir> --label-only        # только интенты
```

## Устойчивость к лимитам API

- OpenAI: конкурентность 32 (лимиты 10M TPM / 10K RPM)
- Gemini: каждая фраза батча = 1 запрос → скользящий минутный RateLimiter (`GEMINI_RPM`) + Retry-After
- DeepSeek: до 1500 одновременных соединений, JSON-режим, температура 0.1
- Qwen (DashScope): батч максимум 10 фраз
- Упавший вариант не валит прогон: помечается skipped и автоматически дожимается (до 3 ретраев)

## Формат данных

Входной CSV — `Запрос;Базовая частотность;Точная частотность;Очень точная
частотность;Является топонимом;Является вопросом`. «Очень точная» — основная
метрика: по ней сортировка, репрезентанты дублей и оценка трафика.
`merge.html` собирает такой файл из любых выгрузок keys.so / Key Collector / Wordstat.
