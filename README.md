## Зачем

Классические кластеризаторы либо гоняют SERP (долго, дорого), либо дают один жёсткий разрез, который нельзя покрутить. Смыслотрон идёт другим путём:

> **Сервер один раз строит деревья слияний, а не кластеры.** Порог объединения, режим связи, минимальный размер группы, гео-разрез, поиск — всё это мгновенные операции над готовым деревом прямо в браузере. Двигаешь ползунок — 30 000 фраз перекластеризуются за миллисекунды, без единого запроса к серверу.

Проверено на живом ядре в 33 726 фраз: полный прогон **всех 11 вариантов эмбеддингов + пофразовая разметка интентов ≈ $1.6** себестоимости (≈ $0.000047 на фразу).

## Чем отличается от SERP-кластеризации

Классические кластеризаторы (KeyAssort, Rush и др.) склеивают фразы по общим URL в топе
выдачи — группировку фактически делает поисковик. Смыслотрон группирует по смыслу,
который видит языковая модель. Разница на практике:

| | SERP-кластеризация | Смыслотрон (эмбеддинги) |
|---|---|---|
| Цена на 30–50К фраз | тысячи ₽ за съём выдачи | **≈ $1.6 за всё** |
| Время | часы–день сбора топов | минуты |
| НЧ и нулевики | выдача пустая/мусорная — хвост разваливается | группируются так же уверенно, частотность не важна |
| Стабильность | выдача меняется каждый день и по регионам | детерминировано: один вход — один результат |
| Синонимы и кросс-язычность | только при случайном пересечении топов | «фото в стиле миядзаки» = «фото в стиле ghibli» из коробки |
| Смена порога группировки | пересбор проекта | ползунок в браузере, мгновенно и бесплатно |
| Взгляд на ядро | один | 11 моделей эмбеддингов + A/B-консенсус |

Подходы дополняют друг друга: SERP отвечает «пустит ли поисковик эти запросы на одну
страницу сегодня», эмбеддинги — «одинаковый ли у запросов смысл и интент». Рабочая
схема: структура ядра — Смыслотроном за минуты, спорные коммерческие группы при
желании довалидируются выдачей.

## Как это работает

<p align="center">
  <img src="docs/assets/pipeline.jpg" alt="Пайплайн: CSV → дедуп → эмбеддинги → деревья → интенты → браузер" width="100%">
</p>

```mermaid
flowchart LR
    A["CSV<br>Keys.so · Key Collector · Wordstat"] --> B["Маппер колонок<br>+ умные шаблоны форматов"]
    B --> C["Дедуп смысловых дублей<br>леммы + чанки предлогов + косинус"]
    C --> D["Эмбеддинги<br>до 11 вариантов, инкрементально"]
    D --> E["HAC-деревья<br>complete / average / single"]
    E --> F["Интенты<br>DeepSeek, пофразово"]
    F --> G["Браузер<br>срез дендрограммы union-find"]
```

1. **Маппер колонок.** Любой CSV/TXT: автоопределение разделителя и колонок, вордстат-нотация (`Wordstat`, `"!Wordstat"`, `"[!Wordstat]"`), флаги топонимов и вопросов. Подтверждённые маппинги запоминаются по подписи заголовка — знакомый формат в следующий раз размапится сам.
2. **Дедуп смысловых дублей.** Кандидаты по мешку лемм (pymorphy3), защита от ложных склеек через чанки предлогов и эмбеддинг-пороги: «молитва матери о дочери» и «молитва дочери о матери» — разные смыслы и НЕ склеиваются. Частотности дублей суммируются в представителя.
3. **Эмбеддинги.** До 11 вариантов на выбор, кэш инкрементальный: докинул фразы в проект — доэмбеддится только хвост.
4. **HAC.** Три дерева на вариант (Hard / Средний / Soft), сериализуются в компактные бинарники для браузера.
5. **Интенты.** DeepSeek размечает каждую уникальную фразу (информационный / коммерческое исследование / транзакционный / навигационный) — разметка не зависит от порога кластеризации и не протухает при перекрутке ползунка.

## Варианты эмбеддингов

| Ключ | Модель | Характер |
|---|---|---|
| `openai` | OpenAI text-embedding-3-large, 3072d | базовый, аккуратный |
| `gemini` | gemini-embedding-2, CLUSTERING | базовый, для кластеризации |
| `gem_sim` | gemini-embedding-2, SEMANTIC_SIMILARITY | «склеивающий» |
| `gem_query` | gemini-embedding-2, RETRIEVAL_QUERY | поисковый |
| `lemma` | OpenAI по лемматизированному тексту | без влияния словоформ |
| `intent` | OpenAI с интент-префиксом | интентная близость |
| `voyage` | voyage-3-large, 2048d | перефразировки, «склеивающий» |
| `qwen` | Qwen text-embedding-v4, 2048d | гибрид, самый дешёвый |
| `ensemble` | конкатенация openai+gemini | бесплатно из базовых |
| `openai1536` | матрёшечная обрезка до 1536d | бесплатно |
| `gemini768` | матрёшечная обрезка до 768d | бесплатно |

## Просмотрщик

Всё пересчитывается на клиенте — мгновенно:

- **Ползунок силы объединения** + режимы связи Hard / Средний / Soft с живой статистикой среза;
- **A/B/N-сравнение** вариантов эмбеддингов колонками: зелёная папка — состав совпал во всех вариантах, красная — расходится (и с кем именно);
- **Сравнение сохранённых шаблонов** колонками — два пресета кластеризации бок о бок;
- **Режим анализа**: неограниченные столбцы, в каждом свой поиск — видно, в какие группы попадают отслеживаемые запросы;
- **Целевое гео** со списком синонимов («москва, мск, мо») — фразы своего региона сливаются с безгеошными, чужие города режутся в отдельные папки;
- Фильтр по частотности, поиск с подсветкой (включая склеенные дубли), интент-чипы у фраз и папок, кнопки Я/G — открыть выдачу Яндекса/Google по фразе, копирование кластера, экспорт текущего среза в CSV;
- Пополнение проекта «бесконечно»: дубли схлопываются, новое доэмбеддивается инкрементально, интенты доразмечаются только для новых фраз;
- Отдельная страница «Объединить CSV» — склейка любых выгрузок в один файл прямо в браузере, без загрузки на сервер;
- Все настройки и шаблоны хранятся в БД на аккаунт — переживают перезагрузку и другое устройство.

## Себестоимость

| Статья | На 33 726 фраз |
|---|---|
| Эмбеддинги OpenAI + Gemini | ~$0.25 |
| Voyage + Qwen | ~$0.10 |
| Интенты DeepSeek (23 940 фраз) | ~$1.23 |
| **Итого, все 11 вариантов + интенты** | **≈ $1.6** |

Расходы считаются по факту на каждый прогон и копятся в карточке проекта: раскладка по провайдерам, цена за запрос и за кластер.

## Быстрый старт

```bash
git clone https://github.com/VKirill/smyslotron && cd smyslotron
cp .env.example .env        # вписать ключи API
uv run uvicorn app:app --host 127.0.0.1 --port 8090
```

Статика `web/` отдаётся любым веб-сервером как `/semantika/`, API проксируется на `:8090`. Пайплайн можно гонять и руками:

```bash
uv run pipeline.py <project_dir> --variants openai,gemini,qwen
uv run pipeline.py <project_dir> --label-only        # только интенты
```

Настройки DeepSeek (модель, ризонинг, уровень мышления) — через `.env`, см. `.env.example`.

## Большие ядра: автоаренда GPU на Vast.ai

Построение деревьев требует полной матрицы сходства N×N (100 000 смыслов ≈ 90 ГБ). Если
локальной RAM не хватает, пайплайн **сам** арендует видеокарту на [Vast.ai](https://vast.ai)
с нужной VRAM (ступени 24 / 48 / 80 / 94 / 140 ГБ — 4090 / A6000 / A100 / RTX PRO 6000 / H200;
float32, при нехватке — float16), заливает туда вектора, строит деревья на CUDA алгоритмом
nearest-neighbor chain (`pipeline_lib/gpu_hac.py` — полное дерево, точен для всех трёх режимов,
разбиения совпадают со scipy), забирает домой три `.bin` по ~1 МБ и **уничтожает машину** —
всегда, даже при ошибке. Матрица нужна один раз: дальше вся работа идёт по деревьям в браузере.

**Замер на рабочем ядре 104 602 смысла:** H200 $3.3/ч — весь цикл с арендой **7 минут, $0.33–0.39**.
Для сравнения, CPU-машина с 503 ГБ RAM строила те же деревья больше часа — поэтому CPU-путь удалён.

```bash
VASTAI_API_KEY=...        # включает автоаренду; без ключа — понятная ошибка с расчётом памяти
VASTAI_GPU_MAX_DPH=4.0    # потолок цены карты, $/час
```

Аренда учитывается в себестоимости проекта отдельной строкой. Фраза оплачивается
эмбеддинг-провайдеру один раз навсегда — глобальная база `embeddings.db` общая для всех проектов.

## Стек

`Python 3.12` · `FastAPI + SQLite (WAL)` · `numpy / scipy / pymorphy3` · `vanilla JS` — три статических HTML без сборки и фреймворков. Пайплайн — самодостаточный uv-скрипт с inline-зависимостями.

Устойчивость к лимитам API из коробки: скользящий RateLimiter для Gemini, до 1500 параллельных соединений к DeepSeek, батчи по правилам каждого провайдера, автодожим упавших вариантов без перезапуска всего прогона.

## API

REST под префиксом `/semantika/api`: авторизация (почта+пароль, cookie-сессии), загрузки с автомаппингом, проекты (создание / запуск / пополнение / удаление), разметка интентов, целевое гео, пользовательские настройки, выдача деревьев и результатов. Полный справочник — [docs/api.md](docs/api.md).
