# Обзор проекта

## Что это

**Смыслотрон** (внутреннее имя semantika-web) — мини-SaaS для кластеризации SEO-ядра
по эмбеддингам. Пользователь загружает CSV с поисковыми фразами и частотностями,
сервис строит семантические кластеры и отдаёт интерактивный просмотрщик, где
кластеризацию можно перекраивать в реальном времени.

Целевой пользователь — SEO-специалист, который группирует ядро (сотни — сотни тысяч
фраз) по смыслу, чтобы спроектировать структуру сайта и посадочные страницы.

## Ключевая идея

**Сервер считает деревья, а не кластеры.** Дорогая часть (эмбеддинги, матрица
сходства, иерархическая кластеризация HAC) выполняется один раз и сериализуется
в компактные бинарные деревья слияний. Дешёвая часть (выбор порога, режима связи,
минимального размера, гео-разреза, поиска) — это срез готового дерева алгоритмом
union-find прямо в браузере. Поэтому ползунок «силы объединения» пересчитывает
30 000+ фраз мгновенно и бесплатно.

Второе следствие: LLM-разметка интентов делается **пофразово**, а не по кластерам —
она не зависит от текущего среза и не протухает, когда пользователь крутит ползунок.

## Из чего состоит

- `app.py` — FastAPI-бэкенд: аккаунты, проекты, загрузки, очередь, выдача данных;
- `pipeline.py` — вычислительный пайплайн, запускается subprocess'ом на каждый проект;
- `web/` — три статических HTML-страницы (vanilla JS, без сборки);
- `semantika.db` — SQLite: пользователи, проекты, шаблоны маппинга, настройки;
- `projects/<uid>/<pid>/` — файловое хранилище данных каждого проекта.

Проект **самостоятельный**, кода с соседним seo-cluster не делит (только читает его
`.env` как fallback-источник API-ключей).

## Что умеет (кратко)

11 вариантов эмбеддингов (OpenAI, Gemini ×3, Voyage, Qwen, леммы, интент-префикс,
ансамбль, 2 матрёшечные обрезки) · дедуп смысловых дублей с защитой от ложных склеек ·
3 режима связи HAC · пофразовые интенты DeepSeek · гео-разрез с целевым регионом ·
A/B/N-сравнение вариантов и шаблонов · режим анализа со столбцами-поисками ·
инкрементальное пополнение проектов · умные шаблоны форматов CSV · подсчёт
себестоимости каждого прогона. Себестоимость полного прогона ядра 33 726 фраз ≈ $1.6.
